# Smeta Bots

Телеграм-боты для учёта расходов и приходов с хранением операций в PostgreSQL и асинхронной синхронизацией в Google Sheets.

## Структура проекта

- `src/` — код приложения, включая domain, application, infrastructure, management, workers и Telegram interface.
- `alembic/` — миграции базы данных.
- `docs/` — план рефакторинга и рабочий чек-лист.

## UX

Бот поддерживает два пользовательских сценария:

- `Расход ₽`
- `Приход ₽`

Сценарий расхода:

1. Пользователь выбирает дату.
2. Выбирает тип кошелька:
   `Проект`, `Взять в долг`, `Вернуть долг`.
3. Если нужен проектный расход, выбирает раздел, категорию и при наличии подкатегорию.
4. Вводит сумму.
5. Для долга дополнительно вводит коэффициент экономии.
6. Вводит комментарий.
7. Бот сохраняет операцию в PostgreSQL и ставит задачу синхронизации в Google Sheets.
8. После сохранения можно удалить операцию через inline-кнопку.

Сценарий прихода:

1. Пользователь выбирает дату.
2. Выбирает раздел прихода.
3. Выбирает категорию прихода.
4. Вводит сумму.
5. Вводит комментарий.
6. Бот сохраняет операцию в PostgreSQL и ставит задачу синхронизации в Google Sheets.
7. После сохранения можно удалить операцию через inline-кнопку.

## Конфигурация

Файл `src/management/projects.yaml` хранит список проектов для `seed_once`.

Переменные окружения:

- `POSTGRES_HOST`
- `POSTGRES_PORT`
- `POSTGRES_DB`
- `POSTGRES_USER`
- `POSTGRES_PASSWORD`
- `GOOGLE_SERVICE_ACCOUNT_JSON` или набор отдельных `GOOGLE_*` полей сервисного аккаунта

`work_chat` и `bot_link` остаются только в YAML/runtime и не записываются в БД.

## Локальный запуск

1. Установить зависимости через Poetry.
2. Подготовить `.env`.
3. Поднять PostgreSQL.
4. Применить миграции:

```bash
alembic -c alembic.ini upgrade head
```

5. Запустить приложение:

```bash
poetry run python -m src.main
```

## Docker

Сборка контейнера выполняется из `src/Dockerfile`.

Запуск:

```bash
docker compose up --build
```
